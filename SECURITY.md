# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately rather than
opening a public issue. Contact the maintainer via the repository's GitHub
security advisory feature or email.

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce.
- Any suggested mitigations.

We will acknowledge receipt within 7 days and aim to provide a fix or mitigation
plan within 30 days.

## Supported versions

Only the latest release on the default branch is supported with security fixes.

## Scope

This project is provided as-is. Please do not test against systems you do not
own or have authorization to test.
